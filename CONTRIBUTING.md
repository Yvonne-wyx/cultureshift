# Contributing

Work Issue-by-Issue and keep changes within the agreed MVP scope. Before implementation, read `AGENTS.md`, the linked Issue, and relevant specifications and architectural decision records. Use test-first development and include verification evidence.

By submitting original source code, you agree that it may be distributed under the MIT License. Documentation and non-code assets require explicit permission for both redistribution and derivative use. Do not submit third-party material unless its license and provenance are documented.

Participation, GitHub repository access, public attribution, and permission to use a person's intellectual property are separate approvals. One does not imply another.

Never submit secrets, personal data, private materials, or unauthorized assets. Treat cultural interpretations as hypotheses and state their evidence and uncertainty. See `CODE_OF_CONDUCT.md`, `SECURITY.md`, `PRIVACY.md`, and `LICENSE_SCOPE.md`.
